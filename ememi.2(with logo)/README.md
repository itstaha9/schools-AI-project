# سامانه مدیریت مدرسه امامی آل آقا

یک پیش‌نمایش فارسی، راست‌چین، واکنش‌گرا و دارک برای شروع طراحی سامانه مدیریت و ارزیابی ماهانه مدرسه.

## اجرا
- فایل ZIP را استخراج کنید.
- فایل `index.html` را با مرورگر باز کنید.
- برای تجربه بهتر، اتصال اینترنت جهت بارگذاری فونت Vazirmatn لازم است؛ در صورت نبود اینترنت، فونت جایگزین استفاده می‌شود.

## امکانات فعلی
- داشبورد مدیریتی با کارت‌های آماری و نمای گزارش
- ناوبری بین بخش‌ها و منوی موبایل
- فهرست نمایشی اعضا، جست‌وجو، فیلتر نقش و افزودن/ویرایش عضو
- فرم ثبت ارزیابی ماهانه
- فهرست فعالیت‌ها و تغییر وضعیت
- گزارش نمونه و خروجی CSV
- تنظیم نام نمایشی مدرسه
- طراحی RTL، تم تاریک، انیمیشن ورود بخش‌ها، hover transition و اسکرول نرم

## نکته مهم
این نسخه **فرانت‌اند نمایشی** است. اطلاعات فقط در حافظه همان صفحه نگهداری می‌شوند و با بارگذاری مجدد ممکن است از بین بروند. هنوز ورود امن کاربران، نقش‌ها و سطح دسترسی واقعی، پایگاه داده، پشتیبان‌گیری، ثبت رویدادها و حفاظت از اطلاعات دانش‌آموزان پیاده‌سازی نشده‌اند. برای استفاده واقعی در مدارس، این موارد باید قبل از انتشار عمومی طراحی و پیاده‌سازی شوند.

## ساختار
- `index.html` ساختار صفحات
- `styles.css` طراحی و واکنش‌گرایی
- `app.js` تعاملات نمایشی


## به‌روزرسانی طراحی
- لوگوی اختصاصی مدرسه در فایل‌های `logo-emblem.jpg` و `logo-emami.png` قرار دارد.
- بخش «نمای کلی» دارای ورود مرحله‌ای کارت‌ها، افکت درخشش، حرکت شناور عناصر، چرخش مدارها، انیمیشن نمودار و تعاملات hover است.
- برای کاهش حرکت، تنظیم `prefers-reduced-motion` سیستم‌عامل رعایت می‌شود.
- داده‌ها هنوز نمایشی‌اند و برای ذخیره واقعی باید بک‌اند و دیتابیس متصل شوند.
